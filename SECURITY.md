# Security Policy

Archguard is **unaudited software**. Use at your own risk, especially with
mainnet funds.

## Reporting a vulnerability

Do **not** open a public issue for security vulnerabilities. Instead, contact
the maintainer directly:

- Telegram: **[FILL IN]**
- Email: **[FILL IN]**

Please include a description of the issue, steps to reproduce, and the impact.
We will respond as soon as possible.

## Scope

This policy applies to both the `archguard-contract` and `archguard-app`
repositories.
